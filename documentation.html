CHICHI Messaging Documentation

This document explains how to set up your account, find people, manage conversations, and send messages in CHICHI.

CONTENTS

01

Getting started

CHICHI is a messaging and community app. Create an account to access chats, profiles, and other available features.

01

Create an account

Open CHICHI, select Sign Up, and follow the on-screen instructions to register.

02

Complete your profile

Add your name and username. You can also add a profile photo and other details.

03

Find people

Open People and search by name to find members. Open a profile to start a conversation.

Existing users: Select Log in and enter your account details.

02

Chats and calls

Open Chats to view your conversations. Select New message to find a person and start a conversation.

Send a text message

Type in the message field and select the send button. Press Enter to send when using a keyboard.

Send an image

Select the attachment button in a chat and choose an image. Your device may ask for permission to access photos or files.

Send a voice message

Select the microphone button to record, then send the recording. Allow microphone access when prompted.

Use emoji

Select the emoji button to insert an emoji in your message.

Calls

Calls are not available yet. The call button currently displays a notice that the feature is coming soon.

03

Search and organize conversations

Use the search field and filters at the top of the Chats screen to find conversations.

Search

Search for a person or message using the search field.

Filter the chat list

Select All, Unread, Favorites, or Archived to view matching conversations.

Message options

Open a message's options to copy, edit, pin, forward, react to, star, or delete it. Available actions can depend on the message.

04

People and profile

PROFILE

Update your details

Open Profile to view your page. Select the edit option to update available profile information and images.

PEOPLE

Browse members

Open People to browse community members. Select a profile to view it and start a chat.

05

Notifications

Use Phone notifications in the account menu to manage notification preferences when the option is available.

Notifications also require permission from your browser or device. Manage or revoke that permission in your system settings.

06

Purchasing code snippets

Code snippets may be available for purchase. To ask about availability and pricing, open People and tap the Admin tag. CHICHI opens a chat with a suggested inquiry in the message field. Review or edit it, then send it when you are ready. Confirm the details directly with the admin before making a purchase.

07

Privacy and support

Keep your sign-in details private and review the privacy policy to learn how information is handled.
